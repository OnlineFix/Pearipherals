## User requirements
- Deliver a single windowed/self-contained `Pearipherals.exe`, with config beside it and no console window.
- Preserve reversible Apply/Restore behavior and never restart the input device from the daemon.
- Three-finger mapping: down=minimize all, up=restore all minimized windows, left/right=Task View. Drag remains opt-in/off by default.
- ScrollDirection=1 (classic wheel direction: swipe bottom-to-top scrolls the page down).
- Verify source tests, frozen build, sidecar config behavior, autostart, and live app before claiming completion.
- Do not overwrite or deploy an EXE until tests/build verification pass. Physical gesture tests require the user.
