Apple Magic Keyboard and Magic Trackpad 2 for Windows

Pearipherals adds Mac-style function keys, custom three-finger gestures, separate keyboard and trackpad battery levels, and low-battery warnings. It runs locally as a portable Windows app, without an account or telemetry.

A companion utility, not a trackpad driver. Magic Trackpad 2 pointer movement and two-finger scrolling require the separately installed mac-precision-touchpad driver. Pearipherals adds controls and features on top; it does not bundle or replace that driver.

Intended for Windows 10/11 x64 with Apple Magic Keyboard and Magic Trackpad 2 over Bluetooth. Not every hardware revision or setup has been validated. USB-C models and Windows on ARM are not claimed as validated here.

Before downloading: unsigned beta

The v1.2.1 EXE has no Authenticode signature. Windows cannot verify its publisher. SmartScreen may warn; Smart App Control may block it without a per-app exception. Do not disable system-wide security protections to run it.

The published binary was inspected and scanned, but was not separately hardware-tested. A clean scan does not guarantee safety. A SHA-256 checksum checks file integrity, not publisher identity or safety. Read the release notes and testing limits before deciding whether to try it.

What Pearipherals adds

Magic Keyboard function keys on Windows

F1/F2 adjust display brightness; F3 opens Task View; F4 opens Windows Search. F6 opens the Windows Snipping Tool selection overlay. F7–F9 control media, and F10–F12 control mute and volume. F5 passes through unchanged.

Hold Ctrl, Alt, Shift or Win to send the original F-key, so shortcuts such as Alt+F4 still work. The Mac F-row can be switched off from the tray. Brightness uses available display controls, with gamma dimming as a fallback; behavior depends on the display and connection.

Magic Trackpad 2 three-finger gestures

Choose Swipes (down to minimize, up to restore, left/right for Task View), Drag for three-finger dragging and text selection, or Off. Normal pointer movement and two-finger scrolling stay with the separate driver.

A natural-scrolling toggle is included. Reconnect the trackpad or reboot after changing it, because Windows reads that setting when the device connects. Four-finger gestures are not handled.

Battery levels and low-battery warnings

The tray shows keyboard and trackpad battery values separately. Fresh readings trigger low-battery notifications at 20% or below, with one critical escalation at 5% or below. A fresh reading of 25% or above rearms that device; charging reports suppress warnings.

Warnings are best effort, not a guarantee before a battery dies. The app must be running and receiving fresh data. Sleeping or disconnected devices, Windows notification settings and Do Not Disturb can prevent warnings. Real low-battery transitions and hardware sleep/wake were not explicitly tested for this release.

Installation and first launch

  1. Check the Windows and Bluetooth hardware requirements above. For Magic Trackpad 2 pointer movement and two-finger scrolling, follow the separate driver’s installation documentation. Keyboard mappings, battery display and monitor controls do not require that trackpad driver.
  2. Read the v1.2.1 unsigned release notes, including the warning, checksum and testing limits. If your security policy blocks the app, do not weaken protections to proceed.
  3. Keep the portable EXE in a persistent folder you control, such as C:\Tools\Pearipherals. When updating, back up the old EXE and its adjacent pearipherals.json, then quit the old instance before replacing files. Preserve the original touchpad-settings backup in that configuration.
  4. Launch only when ready: first launch enables autostart and applies touchpad settings, then explains those changes in a notification. The configuration and optional error log stay beside the EXE.
  5. Open About / status… from the tray to check the version, build identity and observed device state. Choose the function-key and gesture options you want. Keep your previous EXE and matching configuration backup until satisfied with an update.

How to remove Pearipherals

  1. Select Prepare for removal… in the tray, confirm and inspect every result. It disables custom input features, removes startup entries and restores backed-up Windows touchpad settings. Resolve any reported restoration failure before deleting the settings backup.
  2. Select Quit. Preparing for removal does not quit the app or delete files.
  3. Delete the EXE and adjacent runtime files you no longer need: pearipherals.json, pearipherals.err.log and pearipherals-diagnostics.json.

The separately installed trackpad driver is not removed by deleting Pearipherals. See the full removal guide for the manual recovery alternative.

Frequently asked questions

Can I use Apple Magic Trackpad 2 on Windows 11?
The mac-precision-touchpad driver supplies normal pointer movement and two-finger scrolling. Pearipherals is a companion for custom three-finger gestures, natural-scrolling control and battery display. The documented setup is Bluetooth on Windows 10/11 x64; it is not a guarantee for every hardware revision.
Can I use Magic Keyboard F-keys like a Mac?
Pearipherals provides brightness, Task View, Search, Snipping Tool, media and volume actions. Hold Ctrl, Alt, Shift or Win for the original F-key. The keyboard’s Fn key is not exposed over this Bluetooth path.
Why is a battery reading missing, or a warning not showing?
A sleeping or disconnected device may not provide fresh battery data. Missing or stale data is not treated as zero. Notifications also depend on Windows settings and Explorer. Check About / status and the battery documentation.
Why does Windows show an unknown publisher?
The current beta is unsigned. The public source and checksum do not substitute for a trusted digital signature. Review the warning above and do not disable security protections to run it.
Is it free, and does it upload data?
Pearipherals is free and MIT-licensed, with no paid tier, account, telemetry or automatic uploads. Optional diagnostics are saved locally only when requested, for you to review before sharing. Read the application privacy policy.
Where can I report a problem or working setup?
Use GitHub issues or submit a compatibility report. Include product-level details, not serial numbers, Bluetooth addresses or raw HID data. Do not post private configuration or logs without reviewing them.
